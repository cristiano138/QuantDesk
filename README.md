# QuantDesk

Windows 本地 A 股量化交易工作台（Python 3.11+ · FastAPI · React + TypeScript）。

核心体验：实时盯盘 → 行情面板 → 回测 → 模拟盘 → 实盘（QMT 为主力通道），
同一份策略代码零修改跑通三种模式；实盘下单必经服务端三道闸。
与各大主流股票软件结合：QMT/miniQMT、通达信、同花顺（iFinD + 客户端）、掘金、AKShare、Tushare
的**行情通道 + 交易通道 + 板块/公式工作流互操作**（详见下方[通道矩阵](#与主流股票软件结合通道矩阵)）。
**免账号即可用的实时盯盘**（A股 + 港股，只读，看真实行情/当日买卖量/逐笔/分时，
配「新手指引」术语模块）——这条链路不需要任何券商权限，装完就能看真实数据。
项目宪法见 [AGENTS.md](AGENTS.md)；工程方案与决策见 [docs/商业落地工程方案.md](docs/商业落地工程方案.md)。

## 快速开始

```bash
uv sync                          # 安装依赖（Python 3.12）
uv run pytest                    # 测试（network 用例默认跳过）
uv run python -m quantdesk.app   # 启动 API：http://127.0.0.1:8787
```

数据下载（AKShare 免 token）：

```bash
uv run python scripts/download_history.py --symbols 600000.SH --start 2019-01-01
```

前端（开发模式）：

```bash
cd frontend && pnpm install && pnpm dev   # http://localhost:5173（代理 /api /ws → 8787）
cd frontend && pnpm build                 # 产出 frontend/dist（桌面壳与单端口访问需要它）
```

桌面壳（D29）：双击 `启动.bat`——自动起后端 + 打开 pywebview 窗口（先 `pnpm build`，
否则 `/` 返回 503 并提示构建命令）。

## 与主流股票软件结合（通道矩阵）

「结合」有三层：**数据通道**（拿行情/财务）、**交易通道**（下单与回报）、**工作流互操作**
（板块文件与选股公式和客户端互通）。三层都已落地，通道由插件注册表自动发现（宪法第 1 条：
新增通道 = 新增一个文件 + 模块级 `ADAPTER` 导出，核心引擎零改动）。

| 通道（注册名） | 层 | 软件/SDK | 前置条件 | 默认状态 |
|---|---|---|---|---|
| `akshare` | 数据 | 东财 AKShare | 无（免 token） | **可用**（反爬限速 `QUANTDESK_AKSHARE_MIN_INTERVAL`，默认 1s） |
| `tushare` | 数据 | Tushare Pro | tushare.pro 注册 → token 进保险库 | 待 token；含本地精确 qfq，**推荐回测口径** |
| `qmt_xtdata` | 数据 | QMT / miniQMT（xtquant） | 券商开通 QMT 权限 → 客户端登录并启用「极简模式」→ 保险库录入 userdata 目录 + 资金账号 | 代码已接入，**未就绪**（本机无 SDK/客户端） |
| `tdx_aidata` | 数据 | 通达信 | 二者择一：① `pip install pytdx`（社区，免账号）② 通达信官方 SDK | 代码已接入，未就绪时如实上报缺哪个 |
| `ths_ifind` | 数据 | 同花顺 iFinD | 商务开通试用/正式，refresh_token 或账号密码进保险库 | 代码已接入，未就绪（配额三层缓存已实现） |
| `tx_quote` | 数据（只读盯盘） | 腾讯财经公开行情 | 无（免账号免 SDK，能出网即可） | **可用**（批量五档+内外盘，盯盘池轮询主源；非官方接口，UI 红字标注） |
| `em_quote` | 数据（只读盯盘） | 东方财富公开行情 | 无（免账号免 SDK，能出网即可） | **可用**（逐笔/分时/个股扩展字段；自带限速与按主机冷却） |
| `paper` | 交易 | 内置模拟撮合 | 无 | **可用**（`simulation_only=True` 下唯一路由目标） |
| `qmt` | 交易 | QMT / miniQMT | 同 `qmt_xtdata` | 代码已接入，实盘需用户在场 |
| `gm` | 交易 | 掘金终端（gmjsdk） | 掘金注册 → 终端在跑 → Token + 账户 ID 进保险库 | 代码已接入，未就绪 |
| `easytrader` | 交易 | 同花顺客户端 | 同花顺独立下单程序 `xiadan.exe` 路径进保险库 | **默认禁用**（非官方接口，稳定性低；启用需设置页确认文本） |
| `federated` | 数据（路由） | 以上数据通道的降级组合 | — | **可用**（历史可降级；实时主源单一，宁停勿错） |

- 面板入口：`/channels`（通道管理）—— 三态如实上报 `ready / unready(缺哪个 SDK) / disabled`，
  一键探活、凭据表单、对账差异列表。**新增通道不需要改前端**（表单与列表由后端元数据驱动）。
- 谁当主源、降级顺序，在「设置 → 行情通道路由优先级」里改（`feed_priority_history/realtime/financial`），
  服务端按注册表校验通道名：写错名返回 400 并列出可选值；允许先把还没装 SDK 的源写上，装好即用。
  实时只认主源——主源断线不切第二源，避免两条口径拼出一条失真时间轴。
- SDK 全部是**可选依赖**，不进 `pyproject`：适配器顶层不 import，缺失时给安装引导而不是堆栈。
  例外是 `tx_quote` / `em_quote`——它们用主依赖 `httpx` 直连公开接口，**免账号、免 SDK、装好即 ready**。
- 「接入完成」≠「接入可交付」：六个通道凡依赖真机 SDK 的口径都归档在
  [`docs/integration/`](docs/integration) 的**在线核对清单**，须在装好 SDK 的机器上逐条勾选。
- 新增通道流程见 [`docs/adapter_dev_guide.md`](docs/adapter_dev_guide.md)。

## 实时盯盘（A股 + 港股，只读）

`/watch`（实时盯盘）是**看盘产品**，不是交易页面的子集：默认盯盘池 4 只 A股 + 4 只港股，
`600000.SH` / `00700.HK` 这类代码随便粘（`hk00700`、`700.HK`、`116.00700` 都认）。

- **看什么**：整池快照（价/涨跌/量/额/换手/量比/市值）→ 点开单只看五档、分时曲线、
  当日逐笔（可按方向筛、分页）、日 K；
- **当日买卖量**：主口径 = **外盘/内盘**（主动买/主动卖累计量）。A股两源互证——腾讯 `outer` 与
  东财 `f49` 实测逐位相等；港股腾讯接口不给，取东财 `f49` 单源（实测 00700 外盘 10,473,682 +
  内盘 8,026,423 = 总量，自洽）。逐笔只做**小/中/大/特大单分层**与明细。东财逐笔**含盘后成交**，
  与官方总量实测差 A股 +8.11%、港股 −3.14%——这个差直接显示在界面上（`tick_vs_official_pct`），
  不偷偷二选一；
- **逐笔方向码不靠猜**：`1/2/4` 谁是买谁是卖，每天用官方内外盘反解校准；判不准时用默认映射
  并在界面标 `calibrated=False`（且**不写当日缓存**——盘前一个坏样本不该毒一整天）。
  港股逐笔只有 `1/2`（实测 18961 笔无中性码），中性桶为空是接口边界，不是解析漏了；
- **每日自动**：盘中轮询整池 → 15:05 / 16:10 定格 A股与港股当日买卖量（落 `daily_flow`，可回看）→
  15:25 / 16:25 自动回补日 K 到 Parquet（`backfill`：只补缺、不覆盖已有行、写入后自检）；
- **休市不外呼**：两市都收市时自动路径直接返回缓存并说明原因，面板显示「休市中：未外呼」；
  只有点「刷新」（`force`）才真打接口——公开接口有反爬，收盘后反复撞等于自我封禁；
- **只读是服务端事实不是 UI 约定**：`RiskGate` 在闸口对 `.HK` 一律拒单（`submit` 与 `validate`
  两处都拦，四种代码写法都命中），盯盘 API 与前端**不存在**任何下单/撤单/持仓写入口。

`/guide`（新手指引）与盯盘页同级入口：103 条术语 × 10 类（市场 / 行情 / 资金流 / K线 / 指标 /
估值 / 委托 / 风险 / 港股 / 数据），每条给「一句话解释 + 展开 + 算例 + 常见误解 +
在哪个页面能看到 + 关联术语」，支持搜索与 `?c=&t=` 直达。术语表在 import 期自检
（重复 slug、未知分类、关联术语断链直接抛错）——内容型数据坏了不会报错，只会静默缺条。

## 手机看盘（本地单文件 App，`QuantDesk-App/`）

交付目录 `QuantDesk-App/` 里是三样成品，不依赖构建工具链：

- `手机看盘.html`：拷到手机用浏览器打开即可，可「添加到主屏幕」当 App 用。行情由手机
  自己向公开来源取数（腾讯 / 东方财富 / 同花顺三个来源可切），**不连电脑、不连任何服务器**；
  自选股存在手机浏览器本地。给最新价、量额、官方外盘/内盘与主动买占比，点开一只看五档、
  当日买卖量分档、分时与最近 120 个交易日日 K。全程只读，没有任何下单入口。
- `电脑端启动.bat`：纯 ASCII + CRLF，先探本机是否已有正常运行的程序，再启动并打开桌面窗口。
- `使用说明.txt`：手机三种装法、同花顺 / 南京证券的真实接入边界（券商 App 无对外接口，
  能接的只有电脑端同花顺独立下单程序与券商 QMT 权限）、数据与隐私说明、本版未做的事。

按「只本地运行」执行：端口仍只绑 `127.0.0.1`，没有做局域网配对，也没有产出 .exe/.apk
（打安装程序需要先装打包工具链，本轮按要求不装）。

## 回测结果可回看

- **跑完就有明细**：成交、权益曲线、日志分块落 `backtest_detail`，刷新页面/重启后仍能打开历史运行；
  存储异常时如实显示 `detail_source=none` 与 `partial`，不给一块假装有数的空表；
- **可以取消**：进度卡有「取消这次运行」，终态含 `cancelled / interrupted`；取消的运行保留
  已完成明细，指标按设计留空（不是算不出来，是样本不完整）；
- **空跑会明说**：策略参数 `symbol` 不在本次标的内时 0 成交，运行结果首条日志直接写清
  哪个标的、本次有哪些标的、怎么改——不再让"配置不一致"看起来像"策略没信号"。

## 数据管理

`/data` 页三类能力：**降级链自述**（当前历史/实时/财务分别会走哪个源）、**下载任务**
（按标的与周期拉历史，进度可查，全部落本地 Parquet）、**本地盘点**（哪些标的有哪年数据、
多少行、最大间隔），财务数据同理。缺数据时页面给的是"下一步该点哪"，不是一句"本地无数据"。


## 工作流互操作（不需要任何券商权限）

`/interop`（软件互操作）把 QuantDesk 的自选与选股结果**送进**用户已经在用的股票软件，
也把它们的结果**取回来**：

- 通达信 `.blk`（GBK，市场位 1沪/0深 + 6 位代码）导入/导出，可直接写入客户端
  `…\T0002\blocknew\`（需在设置页配置通达信安装目录；未配置时只产出下载文件，不假装写成功）；
- 同花顺/东财 TXT 板块（每行 6 位裸代码）双向；
- 条件选股公式**方言编译**：一条规则同时编译成通达信与同花顺公式，且**回测求值与公式同源**
  （ma_cross / macd_golden / rsi_threshold / volume_spike），避免「软件里选出来、回测里不是」；
- 历史信号扫描：本地 Parquet 上按规则批量出信号，导出成板块文件后即可在客户端里看。

北交所 `.blk` 市场位未实测 → 默认跳过并在结果里显式告知，不猜前缀。

## 凭据保险库

账号 / token / 资金路径只进 `data/credentials.vault`（Windows DPAPI 加密，
`quantdesk/core/secrets.py`）：

- **只写不读**：设置页保存后不再回显明文，只显示前 4 位 + `***`；API 与日志同样拿不到明文；
- 密文与**本机 Windows 账户**绑定——换机或重装系统后**无法还原**，需要重新录入。
  备份 `data/` 时请把这条记住（`credentials.vault` 拷走也没用）；
- 非 Windows 或 DPAPI 不可用 → 抛配置错误并引导「请只用模拟盘」，**绝不退化成明文存储**；
- 历史遗留：AKShare 免 token 通道仍可用 `.env`（`QUANTDESK_TUSHARE_TOKEN` 等环境变量），
  新接入的凭据一律走保险库。

## 实盘安全（宪法红线，任何代码不得绕过）

1. **全局模拟盘开关**默认 ON——一切下单路由内置模拟撮合；
   切实盘需在「设置」页输入确认文本（`我知晓并承担实盘交易风险`）；
2. **A 股规则校验**（闸②）：T+1 可用 / 整手 / 委托价 ∈ [跌停,涨停]（复权价误用兜底拦截）/
   资金充足 / 单票市值上限 / 日委托数上限（后两项是**热参**，改设置即刻生效）；
3. **实盘二次确认**（闸③）：先落库 `PENDING_CONFIRM` → WS 推送弹窗 → 10s 超时
   `EXPIRED_CONFIRM` 自动作废；通道断线一律 fail-closed 拒单（不排队不重试）；
4. **闸门在服务端，不在弹窗**：确认文本由服务端校验（`GATED_FIELDS`）——三类危险写入
   （关模拟盘 / 启用 easytrader / 切实盘通道）缺确认文本直接 400；策略代码 `ctx.buy()` 产生的
   下单意图同样走 `RiskGate`，不存在「程序化就绕过闸」的路径；
5. **周期对账**：`/channels` 页可对账，通道快照 vs 本地库，差异（缺单/状态不符/漏成交/
   持仓或资金不符）落库并以 RISK 事件上报；模拟盘同样自检。**「本轮无差异」不算差异**——
   审计心跳默认不进待处置列表（勾选「含每轮无差异记录」才出现），差异项可写结论认领，
   红条不会因为每轮心跳越堆越长；
6. **港股只读**：本工作台的港股定位是「看盘」，`RiskGate` 对 `.HK` 下单意图一律拒单
   （`engine/riskgate.py`，`submit` 与 `validate` 两处都拦）——不是没接通道，是**故意不接**；
7. 全部数据本地存储（SQLite WAL + Parquet）；敏感信息只进保险库（不入库明文、不入 git、
   不进日志）；后端只绑 127.0.0.1（写死，不提供配置项）。

## 常见故障排查

| 现象 | 处置 |
|---|---|
| AKShare 拉数中断/报 `ConnectionLostError` | 触发了限流熔断（封禁期内重试会延长封禁）。等 5/15/30 分钟冷却后重跑；长期放缓：`QUANTDESK_AKSHARE_MIN_INTERVAL=3.0` |
| miniQMT 掉线 | 通道状态灯变红；RiskGate fail-closed 拒单属预期。重启 miniQMT 登录后适配器重连并重放订阅 |
| easytrader 控件丢失 | 适配器自动截图到 `data/logs/`；锁定同花顺客户端版本、操作期间勿动鼠标键盘、建议独立 Windows 账户 |
| 双击 `启动.bat` 没窗口/报一串乱码「不是内部或外部命令」 | 两类原因，都已在仓库里根治：① **`.bat` 必须是 CRLF 且正文纯 ASCII**——`cmd` 按字节偏移读批处理，裸 LF 或多字节中文注释会让解析器错位，把 `-m quantdesk.app` 切到中间当命令执行；② **8787 被别的后端占着**（上一条会话残留、或你已开过一次）。现在的脚本会先探 `http://127.0.0.1:8787/api/system/health`，健康就直接开窗口不再重复起后端，不健康才启动。排查：`netstat -ano \| findstr 8787` 看 PID，再 `taskkill /PID <pid> /F` |
| 后端 8787 被占用 | `netstat -ano \| findstr 8787` 找 PID 结束旧进程；端口经 `QUANTDESK_PORT` 修改（监听地址不可改） |
| 回测报「本地无数据」 | 先在数据管理页/命令行下载对应标的与周期（K 线全部走 Parquet 本地缓存，不外呼） |
| 待确认单重启后还在？ | 在。重启后 `restore_pending()` 从库重载，确认窗口重新起算 |
| 通道页显示「未就绪 / 缺 xtquant」等 | 正常状态，不是 bug：SDK 是可选依赖，本机没装就如实上报。按卡片的 `prereq` 一句话做（装 SDK / 登录客户端 / 录凭据），点「探活」复查。装配失败后 15s 冷却，不会每单去撞一次连接 |
| 打不开 `/`（桌面壳空白） | 前端未构建。`cd frontend && pnpm build` 产出 `frontend/dist`，后端才托管 SPA；dist 缺失时 `/` 返回 503 并给构建指引 |
| 互操作导出「客户端目录未配置」 | 设置页填通达信/同花顺安装目录（指向客户端根，代码自己找 `T0002/blocknew`）。未配置时只给下载文件，不假装写成功 |
| 对账差异列表有红项 | 通道与本地库不一致（缺单/状态不符/漏成交/持仓或资金不符）。这是设计出来的告警，不是崩溃：核对客户端里的真实委托后，在列表里写一句话结论并「标为已处置」；「本轮无差异」只是审计心跳，勾掉「含每轮无差异记录」就不会占位 |
| 回测结果页明细是空的 | 看来源标注：`detail_source=none` 表示这次运行没有落明细（旧运行或存储异常），`partial` 表示只存了一部分；都不是"前端坏了"。取消的运行按设计只保留已完成明细、指标留空 |
| 回测 0 成交但策略逻辑看着没问题 | 先看结果首条日志有没有「空跑提示」：策略参数 `symbol` 不在本次标的内时，0 成交是配置不一致，不是没信号 |
| 运行日志越来越多 | 设置页「运行噪音保留期」（`log_retention_days`，默认 90 天）控制每日 18:40 清理，只清运行日志与对账无差异心跳，差异记录与回测明细不动 |
| 凭据保存后看不到明文 | 保险库只写不读，只显示前 4 位 + `***`。忘记只能重录；换机/重装系统后旧密文不可还原 |
| 盯盘页显示「休市中：未外呼」 | 预期行为，不是坏了。两市收盘后自动路径不再打公开接口（防反爬自封），点「刷新」按钮才强制外呼；数据是当日收盘定格值 |
| 盯盘买卖量与逐笔合计不相等 | 东财逐笔**含盘后成交**，官方外盘/内盘不含，实测差 +8.11% 属口径差。界面同时显示 `tick_vs_official_pct`；主口径永远是官方内外盘，逐笔只做分层 |
| 港股买卖量与 A股口径不同 | 腾讯港股接口不给内外盘，改取东财 `f49`（单源，无第二源互证）。看 `calibrated` 标注：`False` 表示方向码没与官方对齐、用的是默认约定（2=买/1=卖）。港股逐笔只有 `1/2`，中性桶为空属正常 |
| 港股详情里「涨停/跌停」不见了 | 预期：东财对 `.HK` 复用 `f51/f52` 给的是 **52 周最高/最低**（实测 00700 为 656.7/375.2），不是涨跌停。后端已按市场分键输出 `wk52_high/wk52_low`，前端对港股显示「52周最高 / 最低」 |
| 买卖量显示「本标的暂未取到官方内外盘」 | 冷启动/新标的时快照还没落缓存。现在会在调用点补取一次（`_ensure_live`）；若两个源都没给该字段则如实降级为逐笔聚合并标注，不会假装是官方口径 |
| 列表里一排最新价 0.0 | 休市时打开页面、且缓存里只有刚点开过详情的少数几只——旧逻辑按"缓存空不空"决定要不要种快照，一只在缓存里就以为整池种过了。现在按标的逐个补缺（`refresh_auto`），补不上的标的 300s 冷却内不反复外呼，原因会写在提示里 |
| 明细/逐笔「限流冷却中，还需 Ns」 | 东财 `push2` 把连接掐了 → 该主机冷却 60s（冷却期内一次都不再外呼，这是防封禁不是卡死）。盯盘池刷新走腾讯，不受影响；别连续猛点刷新 |
| 分钟 K 线周期与请求不符 | 已修（东财 `klt` 是分钟数不是秒数）。自查方法：请求 5 分钟线，返回 `dt` 间隔中位数应为 5；接入卡第 8 节有真机核对项 |
| 术语页搜不到某个词 | 术语按「命中次数 + 词条名加分」排序，别名也进索引（`/api/guide/terms?q=`）。确实没有的词属新增内容，不是检索故障 |
