QuantDesk 本地版使用说明（手机 App + 电脑 App）
================================================

这一版按你的要求做成「只本地运行」：不部署服务器、不建云端账号、不对外开放端口。
所有行情、自选、回测、运行记录都存在你自己这台机器（手机）上。

现在两端都是**装出来的 App**，不再是打开一个网页：
  电脑 → QuantDesk-安装程序.exe → 桌面与开始菜单出现「QuantDesk 看盘台」图标
  安卓 → QuantDesk-看盘-1.0.apk → 手机桌面出现「QuantDesk 看盘」图标


一、电脑上怎么装、怎么用
------------------------------------------------
1) 双击本目录里的「QuantDesk-安装程序.exe」，点确定。它会：
   · 在桌面和「开始菜单 → 所有应用」里放一个带图标的「QuantDesk 看盘台」
   · 在「设置 → 应用 → 已安装的应用」里登记一条，带卸载入口
   · 不复制、不移动你的行情数据，只是把软件登记进系统

2) 以后打开软件：双击桌面图标，或开始菜单里搜「QuantDesk」。
   图标背后做的事只有三件：
   · 先看本机 127.0.0.1:8787 是不是已经有程序在跑；在跑就直接把窗口调到最前
   · 没在跑就自己把它带起来（第一次约 10~30 秒，窗口上方有进度提示）
   · 打开原生看盘窗口：实时盯盘 / 行情面板 / 回测报告 / 实盘监控 / 行情与交易 /
     软件互操作 / 数据管理 / 新手指引 / 使用手册 / 报备清单 / 设置
   它不是浏览器标签页，没有地址栏，也不联网——只连自己这台电脑。

3) 不想要了：「设置 → 应用 → QuantDesk 看盘台 → 卸载」，或直接运行
   QuantDesk.exe /uninstall
   卸载只删图标和登记，行情数据与软件本体都留在原目录，不会误删任何东西。

4) 老的「电脑端启动.bat」仍然可用，效果和双击图标一样（给习惯命令行的人留着）。

默认是模拟盘：任何委托都由内置模拟盘执行，不动真钱。


二、手机上怎么装
------------------------------------------------
【安卓】装 QuantDesk-看盘-1.0.apk（约 53 KB，很小，因为它只是外壳 + 一个页面）
  1. 把这个 .apk 传到手机：微信「文件传输助手」发给自己、数据线拷贝、或你自己的网盘。
  2. 在手机上点开它，系统会提示「不允许安装未知来源应用」——按提示允许这一次安装即可。
     （小米/华为/OPPO/vivo 的菜单名字略有不同，都在「设置 → 应用 → 特殊应用权限」这一类里。）
  3. 装完桌面出现「QuantDesk 看盘」图标，点开就是 App，不是浏览器页面。
  4. 它不需要你的电脑在线，也不连任何自建服务器；唯一的联网动作是手机自己
     向公开行情取数，所以出门用移动网络一样能看。

  关于「未知来源」：这个包是用工程上标准的 Android 工具（aapt2 / d8 / zipalign /
  apksigner）打出来的，签名是本地自签名（密钥在本目录 android\qd.keystore）。
  自签名意味着系统会弹一次安全提示，这是正常的；也意味着以后升级必须用同一个密钥
  重打，才能覆盖安装而不必先卸载。它没有上架应用商店——上架需要开发者账号与备案，
  那是另一件事。

【iPhone】目前只能走浏览器 + 添加到主屏幕
  iOS 不允许安装没有 Apple 开发者证书签名分发的 .ipa，本机自建工具做不出可安装的
  iPhone 包（需要一台 Mac + 付费开发者账号）。能做到的最接近形态是：
  把「手机看盘.html」发到 iPhone → 用 Safari 打开 → 分享 → 「添加到主屏幕」。
  加完是独立图标、全屏无浏览器地址栏，效果接近 App，但本质仍是网页。
  这一条我不粉饰：iPhone 上要真正的 App，只能走开发者签名，需要你在场另开一轮。


三、这个目录里有什么
------------------------------------------------
QuantDesk-App\
  QuantDesk.exe                 电脑端 App 入口（双击打开软件）
  QuantDesk-安装程序.exe         电脑端安装（图标 + 「应用」列表登记）
  QuantDesk-看盘-1.0.apk         手机端 App（安卓直接安装）
  手机看盘.html                 手机页面本体（也是 APK 里随包的那一份；iPhone 用它）
  电脑端启动.bat                老的命令行启动方式，仍可用
  使用说明.txt                 本文
  appicon.py                    两端共用图标的画法（纯 Python 画，不依赖图像库）
  android\                      手机端 App 源码：清单、外壳代码、构建脚本、自签名密钥
  pc\                           电脑端 App 源码：C# 启动器与安装器、图标、构建脚本

想重新出包（改完页面或想升版本号时）：
  uv run python QuantDesk-App\android\build.py    # 重新打 APK
  uv run python QuantDesk-App\pc\build.py         # 重新打电脑端两个 exe
电脑端只用 Windows 自带的 C# 编译器，不需要装任何东西；手机端需要一次性的
Android 构建工具（aapt2/d8/zipalign/apksigner + android.jar），放在临时目录，
用完已按你的要求删掉了。要重打 APK 时告诉我，我再把工具链拉一次。


四、同花顺 / 南京证券的接入方法与真实边界
------------------------------------------------
先说结论：手机上的同花顺 App、南京证券 App 都没有对外公开的行情或交易接口，
第三方读不到它们的自选与账户，也不能替它们下单。凡是宣称「手机 App 直接接管下单」
的做法，都是模拟点屏（GUI 自动化），既违反客户端使用条款，又极不稳定，真钱场景不能这么干。

能接的只有下面这几条，本项目都已按通道形式预留，装好/开通后在「行情与交易」页点亮：

1) 同花顺公开行情（只看盘，已在手机 App 里做成一个来源）
   · 覆盖 A 股；不提供官方外盘/内盘口径，所以买卖量结构请以腾讯/东方财富为准
   · 非官方软件，稳定性低，界面会如实标注

2) 同花顺「独立下单程序」（电脑端，通道已接入，默认禁用）
   · 这是同花顺 Windows 客户端自带的下单程序，社区里通常覆盖 70~80 家券商，
     南京证券一般在支持列表内，但必须在你自己的机器上实测确认
   · 启用路径：设置页 → 打开「同花顺客户端下单（非官方）」→ 输入风险确认文本
   · 首次使用要人工登录一次同花顺下单程序，并在设置页填好它的安装目录
   · 它是模拟键盘鼠标操作客户端：约 3 秒一笔、客户端升级就可能失效、操作期间不要动鼠标
   · 建议先按「只看盘 + 只查询」用：查资金、查持仓、查委托，确认回报对得上再谈交易

3) 券商官方程序化通道 QMT / miniQMT（电脑端，通道已接入，需券商开权限）
   · 这是唯一稳定的自动下单路径。南京证券是否提供、给哪个版本，要问它的客户经理
   · 常见硬性条件（各家略有差异）：近 20 个交易日日均证券资产达标
     （miniQMT 常见 10 万，标准 QMT 30~50 万）、风险测评 C4 积极型及以上、
     6 个月以上 A 股实盘成交经验、本人实名账户无休眠冻结、
     签《程序化交易风险揭示书》并完成交易所程序化交易报备
   · 权限到位后：装好券商发的客户端 → 登录并开启「极简模式（独立交易）」→
     在「行情与交易」页填行情数据目录与资金账号 → 设置页切实盘
   · 切实盘后每一笔委托仍要过系统三道检查，并在界面上做 10 秒二次确认

4) 南京证券自己的行情/数据接口
   · 没有公开接口，所以本版不做，也不会用别的数凑一个「看起来像」的结果
   · 要看南京证券的股票，用第 1 条或第 3 条即可：股票代码是同一个，行情口径来自公开来源

一句话：手机上「接入同花顺/南京证券」= 用公开行情看同一批股票（已做成 App），
再加一条「连接器」式的桥——自选页点「＋」把票加进来，「在手机 App 中打开」
一键跳到同花顺/东财/腾讯自选股看同一只票；真正要下单 = 只能在电脑上接官方通道
（通道已预留，等你开通权限/装好客户端再实测）。


五、手机 App 能看什么、怎么用
------------------------------------------------
界面是三个标签页 + 右下角一个「＋」：

自选（默认页）
  · 每只一整卡大字：名称、最新价、涨跌额/幅、今开/昨收/最高/最低、
    成交量、成交额、外盘（主动买）及占比、内盘（主动卖）
  · 点卡片任意位置 → 跳「图表」页看这只票
  · 刷新节奏默认「极速 1 秒」（腾讯整池源）；切到东财/同花顺会按对方的
    承受能力自动放慢（5 秒 / 10 秒），这是避免被行情服务器拉黑的物理下限，
    不是偷懒——再快拿到的也是同一份数据，还封你 IP

图表
  · 大价格头 + 五档盘口（含涨停/跌停；港股显示 52 周高低）
  · 分时（价格/均价）与日 K（MA5/10/20/60，前复权，120 根）
    双指捏合缩放、单指拖动、点任意一根 K 线读出当日开高低收量额
  · 当日买卖量分层（小/中/大/特大单，按单笔成交额，含盘后成交）

连接（右下角 ⚡，或自选页的「＋」）
  · 行情源：腾讯 / 东方财富 / 同花顺，各自可「检测」连通、可切换使用中来源
  · 「＋ 选股票」：按名称/拼音首字母搜索，或按板块（沪市主板/深市主板/创业板/
    科创板/北交所/港股主板）翻页挑选——不用记代码；名称自动记住
  · 「在手机 App 中打开」：把当前这只票用手机上装的同花顺 / 东方财富 /
    腾讯自选股打开（装了哪个 App 就跳哪个，没装落浏览器）
  · 自选只存在这台手机里（本机保存，不上传）

不能做（这是设计如此，不是缺失）
  · 不能下单、不能撤单、看不到别人的账户与持仓 —— 全程只读，代码里没有任何写入口
  · 不能读取同花顺 App、南京证券 App 的自选股和账户（原因见第四节）
  · 不缓存历史数据，断网时显示最后一次取到的行情并标注时间


六、数据与隐私
------------------------------------------------
· 全部数据留在本机：行情历史、自选、策略、回测结果、运行记录
· 账户信息只写进本机加密保险箱，不入库明文、不进日志、不进任何上传
· 程序只监听 127.0.0.1，局域网和外部机器都连不进来
· 手机 App 不上传任何数据，行情由手机自己向公开来源请求


七、这一版仍然没做的事（避免误会）
------------------------------------------------
· APK 没有真机装过：这台电脑上没有安卓手机也没有调试线，所以只做到「包结构与签名
  校验通过」（aapt 解析、apksigner 校验、资源与随包页面齐全）。第一次在手机上安装
  如果弹任何错，把提示原文发我，我按提示改包。
· 没有上架应用商店（安卓要软著与开发者账号，iOS 要付费开发者账号 + Mac 出包）。
· 没有 iPhone 安装包，原因见第二节。
· 没有做局域网配对/手机连回电脑（需要先放开端口绑定，你要求只本地运行）。
· 没有做任何自动下单：所有交易通道保持默认关闭，港股按红线只读。
· 电脑端仍是「用这台电脑上已有的 Python 环境跑起来」，不是把解释器一起打进 exe 的
  独立大安装包（那要 PyInstaller + 几百 MB，你说先不要装那些工具）。
